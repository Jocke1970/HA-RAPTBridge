the legacy integration was copied into this repository.

## Prior art and behavioural reference

The compatibility work is informed by:

- [`berra200/home-assistant-rapt-cloud-link`](https://github.com/berra200/home-assistant-rapt-cloud-link),
  an MIT-licensed Home Assistant integration originally created by
  [berra200](https://github.com/berra200);
- [`Jocke1970/home-assistant-rapt-cloud-link`](https://github.com/Jocke1970/home-assistant-rapt-cloud-link),
  which added BrewAssistant-oriented metadata, diagnostics, telemetry
  freshness and BrewZilla profile-runtime behaviour.

Those repositories are used as behavioural references and test oracles. If
source code is copied or adapted in the future, the relevant original
copyright and MIT permission notice must be preserved in the affected files
and documentation.
